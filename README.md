# The_Hail_Mary_Space_Project


An interactive 3D space exploration experience inspired by *Project Hail Mary*.

Built with Three.js and Vite.

This project recreates a fictional star system where users can explore planets, get information, and experience the Petrova (fictional) effect.

<img width="1915" height="965" alt="hailmary-1" src="https://github.com/user-attachments/assets/2d6a5252-6ac1-4afe-9268-58f50cfb58ee" />


## Features

- **Interactive 3D Environment** — Explore a fictional space system rendered using Three.js.
- **Planet Exploration** — View Tau Ceti, Earth, the Moon, Erid, and other planets in the Tau Ceti system.
- **Planet Information HUD** — Hover over a planet to reveal its name, then select MORE INFO to explore additional details.
- **Planetary Animations** — Watch planets rotate.
- **Petrova Effect** — Activate a visual effect that transforms the space environment (similar to the movie).

<img width="1917" height="962" alt="hailmary-2" src="https://github.com/user-attachments/assets/a6dc4822-ad71-4a03-ad7f-fa3753a23a37" />


- **Ambient Audio** — Toggle background music on and off.
- **Camera Controls** — Rotate around the environment and zoom in or out.
